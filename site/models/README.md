# Models

`cooper-camera.glb` is COOPER itself, the model shown in the Warn, Build and Team chapters. It's made from the team's Fusion 360 assembly by `tools/cad_to_glb.py`: one node per part, in metres, lens facing −Z, +Y up, and about 24k triangles in 281 KB. `site/README.md` ("The 3D model") explains how to rebuild it and how the site uses it.
